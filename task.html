30-Day Internship

Your internship journey, one task at a time

TechBridge runs a structured 30-day practical internship made up of 8 hands-on tasks. You will build real web projects, starting with a simple homepage and finishing with a complete internship platform, growing your web development skills with every step.

The 8-Task Roadmap

Follow the line from Day 1 to Day 26. Open any task to see what you will build.

  1. Day1
    Task 1 Completed

    Build the TechBridge Homepage

    Create the first version of the TechBridge website using HTML and CSS.

    Beginner
    What you'll build

    A welcoming homepage that introduces TechBridge. You practise semantic HTML structure, page layout and basic styling, which become the foundation of the whole platform.

    • HTML5
    • CSS3
    View the homepage →
  2. Day4
    Task 2 Completed

    Build the TechBridge Programs Experience

    Create a Programs experience that presents TechBridge's available learning programs.

    Beginner
    What you'll build

    A Programs page that presents each learning program clearly, extending your homepage with reusable cards and consistent navigation.

    • HTML5
    • CSS3
    View the programs →
  3. Day8
    Task 3 In progress

    Build the Internship Tasks Experience

    Create an interface that presents the TechBridge internship tasks and helps users understand the internship journey.

    Beginner → Intermediate
    What you'll build

    The page you are on right now. It lays out all 8 tasks, their days and their difficulty so any new intern can see the full journey at a glance. You practise responsive layout, visual hierarchy and connecting pages into one site.

    • HTML5
    • CSS3
    • Responsive design
  4. Day11
    Task 4 Upcoming

    Build an Interactive Task Tracker

    Use JavaScript to make the internship task experience interactive and allow progress to be tracked.

    Intermediate
    What you'll build

    You bring the tasks page to life with JavaScript: users can interact with tasks and see their progress update. This is your first step from static pages to behaviour.

    • JavaScript
    • DOM interaction
    • Progress tracking
  5. Day15
    Task 5 Upcoming

    Build the Intern Registration Experience

    Create a professional registration/onboarding interface for TechBridge interns.

    Intermediate
    What you'll build

    A polished registration and onboarding flow with well-designed forms, clear labels and friendly feedback, so new interns can join TechBridge smoothly.

    • Forms
    • Validation
    • User experience
  6. Day19
    Task 6 Upcoming

    Build the Task Submission System

    Create an interface through which interns can prepare and submit their task work.

    Intermediate
    What you'll build

    A submission interface where interns prepare their work and hand it in, such as links, notes and confirmations, for each task they complete.

    • Forms
    • Interface design
    • JavaScript
  7. Day22
    Task 7 Upcoming

    Build the Intern Dashboard

    Create a dashboard where an intern can view their profile, progress, tasks, and submissions.

    Intermediate → Advanced Beginner
    What you'll build

    A personal dashboard that brings together an intern's profile, progress, tasks and submissions in one organised view.

    • Dashboard layout
    • Data presentation
    • JavaScript
  8. Day26
    Task 8 Upcoming

    Build the Complete TechBridge Internship Platform

    Combine the different components created during the internship into a complete TechBridge platform.

    Advanced Beginner
    What you'll build

    The finale: you combine everything you have built into one complete, consistent platform, from homepage to dashboard, ready to showcase.

    • Integration
    • Consistency
    • Polish
